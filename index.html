Private by design

Clean the tracking. Keep the destination.

Remove known marketing parameters without guessing that unfamiliar query data is disposable. Every removal is shown before you copy or export the result.

Your URLs stay here.No server, account, analytics, history, or network request is used.

Absolute HTTP and HTTPS URLs only. Unknown parameters are preserved.

Separate with commas. End a rule with * for a prefix.

Keep rules win over built-in and custom removal rules.

Results

Conservative rules

Known tracking names and narrow prefixes are removed. Ambiguous fields such as ref, source, IDs, searches, and page state remain.

Exact preservation

Kept query segments, their order, fragments, paths, and encoded values are retained rather than reconstructed.

Reviewable output

The report names each removed parameter and the rule responsible. Custom keep rules provide an explicit escape hatch.
